- Do not delete backend routes, database tables, persisted records, service modules, or existing business logic during this cleanup.

- Preserve old account-tab query parameters through aliases where practical, especially for links generated by notifications, timelines, signals, or dashboards.

Proposed placement:
- Hide `/health-scores` from sidebar.

- CSAT creation should submit the current `account.id`.
- CSAT should sit alongside existing health score breakdown, score calculators, and score history in `Account360.tsx`.

No backend/database changes are expected unless the current CSAT API validation or permissions block account-scoped usage.
